About

I'm Tony (Yu-Chen) Liu, a Taiwanese engineer living in the U.S. and working as a System Software Engineer at NVIDIA.

I like to learn from first principles. I want to understand a system all the way down: how hardware and low-level software shape what the infrastructure and application layers above them can do. That curiosity doesn't stop at computers. I enjoy picking up knowledge from any field.

Before NVIDIA, I developed RTOS software for RISC-V-based IoT devices at Amazon, worked on silicon emulation projects as an intern at Apple, and built Linux kernel storage and networking features at Synology, including RAID5 read-path tuning and a Netfilter-based network performance module.

Lately I've been digging into the AI software stack: AI accelerator runtimes, inference systems, compilers, agent workflows, sandboxes, and more.
